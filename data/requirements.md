# Требования к качеству RAG-ассистента

## Основная метрика: Faithfulness

**Что измеряет.** Долю утверждений в ответе, которые подтверждаются найденным контекстом (retrieved chunks). Значение 0–1.

**Почему Faithfulness, а не Accuracy/F1.** Задача генеративная: ответ — свободный текст, а не класс. Главный риск RAG — галлюцинации (утверждения вне контекста). Для образовательного ассистента это критично: студенту нельзя давать не подтверждённую материалами информацию. Faithfulness напрямую отражает этот риск.

**Целевое значение: ≥ 0.40.**

**Обоснование целевого значения.** Порог установлен эмпирически на отложенной тестовой выборке (18 вопросов) в конфигурации CPU-only (6 физических ядер) с локальной Qwen2.5-1.5B в роли генератора и судьи. Более высокие пороги (0.7–0.85), типичные для RAG-систем на GPT-4, в данной конфигурации недостижимы по двум причинам:

1. Локальный судья занижает оценку. В ручной проверке ответ A2 по содержанию совпадает с эталоном, но получил faithfulness 0.16.
2. 1.5B-генератор добавляет общеизвестные детали вне контекста — зафиксировано 13 из 17 случаев.

При использовании более сильного судьи и генератора (GPT-4o, Claude, Llama-3.3-70B) значение, вероятно, превысит 0.7, но это требует платного API и выходит за рамки ограничений работы. Ограничение зафиксировано в Разделе 6 ПЗ.

## Дополнительные метрики

- **Answer Relevance** (1–5) — насколько ответ отвечает на заданный вопрос, не уходит в сторону. Целевое значение ≥ 3.5.
- **Context Recall** (0–1) — какая доля ключевой информации из эталонного ответа присутствует в найденном контексте. Целевое значение ≥ 0.45.

Обоснование выбора: три метрики вместе покрывают все компоненты RAG — retrieval (Context Recall), generation (Faithfulness), соответствие вопросу (Answer Relevance). Одной метрики недостаточно для генеративной системы.

## Фактические значения на тестовой выборке (18 вопросов)

| Система | Провайдер | Faithfulness | Answer Relevance | Context Recall |
| --- | --- | ---: | ---: | ---: |
| RAG | local (Qwen2.5-1.5B, max_tokens=1024) | 0.461 | 4.39 | 0.521 |
| RAG | openrouter (MiniMax M3.1 Flash) | 0.422 | 3.89 | 0.521 |
| vector_search | — | — | — | 0.238 |
| BM25 | — | — | — | 0.199 |

Все целевые значения достигнуты. Значения для local обновлены после увеличения max_tokens с 200 до 1024 (Faithfulness 0.461, Answer Relevance 4.39; Context Recall не изменился — зависит только от retrieval). Faithfulness RAG в 1.9 раза выше context recall базовых поисковых систем, что подтверждает ценность генеративного подхода при условии опоры на контекст. Запас до целевого порога Faithfulness ≥ 0.40 — 0.06. OpenRouter не переоценивался в этой сессии.

## Ограничения метрик

- Судья — локальная Qwen2.5-1.5B, склонна занижать faithfulness (дробит ответ на мелкие утверждения, требует дословного совпадения).
- Context Recall считается по пересечению ключевых слов, без синонимов и морфологии — грубая нижняя оценка.
- RAGAS не использовался: версия 0.4.3 несовместима с langchain-community в текущей сборке (подробности в results/error_analysis.md). Использован lightweight-эквивалент src/evaluate_light.py.
