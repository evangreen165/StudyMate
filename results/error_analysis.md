### 2. A2 — faithfulness_failure

**Вопрос:** Чем отличается цикл с предусловием от цикла с постусловием?

**Эталонный ответ:** Цикл с предусловием (while) проверяет условие до выполнения тела и может не выполниться ни разу; цикл с постусловием (do-while) выполняет тело хотя бы один раз, а затем проверяет условие.

**Ответ системы:** Цикл с предусловием **`while`** проверяет логическое выражение **до выполнения тела цикла**. Если условие изначально ложно, тело цикла не выполнится ни разу.

Цикл с постусловием **`do-while`** сначала выполняет тело цикла, а затем проверяет условие. Поэтому его тело выполняется **хотя бы один раз** независимо от начального значения условия.

Схематично:

```cpp
while (условие) {
    // тело цикла
}
```

```cpp
do {
    // тело цикла
} while (условие);
```

То есть:

- **`while`** — проверка условия до тела цикла; возможно **0 выполнений**;
- **`do-while`** — проверка условия после тела цикла; возможно **минимум 1 выполнение**.

**Ответ системы:** **Модель OSI** — это концептуальная схема взаимодействия открытых систем, разделяющая процессы на семь уровней.

**Стек TCP/IP** — это набор конкретных протоколов:
