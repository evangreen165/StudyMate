   n! = n * (n-1)!)

   fact(5) = 5 * fact(4)
                     = 5 * 4 * fact(3)

                     = 5 * 4 * 3 * 2 * fact(1)
                     = 5 * 4 * 3 * 2 * 1

   Таким образом, факториал числа 5 равен 120.

def factorial(n):

### Вопрос 2: Чем отличается TCP от UDP?

Документ: Компьютерные сети (Олифер).

#### RAG

Провайдер: `local`; модель: `Qwen2.5-1.5B-Instruct-Q4_K_M.gguf`.

Время ответа: 27.98 с.

**Ответ:**

TCP и UDP — два протокола транспортного уровня, используемых в сетевом взаимодействии. Они отличаются по ряду аспектов:

1. Цель работы:
   - TCP: передает данные между приложениями.
   - UDP: передает данные между приложениями с меньшей сложностью.

2. Структура данных:
   - TCP: использует сегменты для передачи данных.
   - UDP: передает данные в виде пакетов, которые могут быть отфильтрованы или не доставлены.

3. Применение:
   - TCP: используется при передаче больших объемов данных между приложениями.
   - UDP: используется для передачи данных с меньшей сложностью и быстродействием, таких как голосовые сообщения или видеоигры.

**Ответ:**

TCP (Transmission Control Protocol) и UDP (User Datagram Protocol) — два протокола передачи данных, используемые в интернете. Однако они имеют несколько существенных отличий:

1. Стабильность:
   - TCP обеспечивает стабильную и надежную передачу данных.
   - UDP не гарантирует стабильности передачи данных.

2. Отправка данных:
   - TCP отправляет данные в блоки, которые проверяются на каждом этапе передачи данных.
   - UDP отправляет данные без блокирования и с непрерывной отправкой данных.

3. Количество пакетов:
   - TCP гарантирует корректное и стабильное выполнение всех операций, связанных с передачей данных.
   - UDP не гарантирует корректность или стабильность передачи данных.

Конструктор копирования в C++ используется для создания нового объекта, который является копией существующего объекта. Это позволяет избежать дублирования кода и упрощает управление состоянием объектов.

```cpp
class MyClass {
public:
    int value;

    // Конструктор копирования
    MyClass(const MyClass& other) : value(other.value) { }
};

int main() {
    MyClass obj1(5);
    MyClass obj2 = obj1;  // Копирование объекта

    std::cout << "Value of obj1: " << obj1.value << std::endl;
    std::cout << "Value of obj2: " << obj2.value << std::endl;

    return 0;
}
```
