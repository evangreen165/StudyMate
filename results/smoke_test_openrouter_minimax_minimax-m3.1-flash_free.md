Время ответа: 4.04 с.

**Ответ:**

**Рекурсивная функция** — это функция, которая во время выполнения вызывает сама себя.

Для корректной работы рекурсивной функции нужны:

1. **Базовый случай** — условие, при котором функция завершает вызов и возвращает результат.
2. **Рекурсивный шаг** — вызов функции с изменёнными аргументами, обычно приближающимся к базовому случаю.

Пример — вычисление факториала:

```python
def factorial(n):
    if n <= 1:          # базовый случай
        return 1
    return n * factorial(n - 1)  # рекурсивный вызов
```

Здесь `factorial(5)` вызывает `factorial(4)`, затем `factorial(3)` и так далее, пока не достигнет базового случая.

Рекурсия бывает **прямой** (функция вызывает себя) и **косвенной** (функция вызывает другую функцию, а та — исходную).

### Вопрос 3: Зачем нужен конструктор копирования в C++?

Документ: ООП.

#### RAG

Провайдер: `openrouter`; модель: `minimax/minimax-m3.1-flash:free`.

Время ответа: 5.36 с.

**Ответ:**

Конструктор копирования нужен для создания нового объекта на основе существующего. Он вызывается:

- при инициализации одного объекта другим;
- при передаче объекта в функцию по значению;
