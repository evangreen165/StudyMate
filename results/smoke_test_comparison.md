# Сравнение провайдеров LLM

Дата: 2026-10-20

Контрольные вопросы: рекурсивная функция, отличия TCP/UDP, конструктор копирования в C++.

| Провайдер | Модель | Время RAG (3 вопроса), с | Качество | Ограничения |
| --- | --- | --- | --- | --- |
| local | Qwen2.5-1.5B-Instruct-Q4_K_M.gguf | 26.80 / 27.98 / 24.06 | Ответы релевантны и опираются на найденные фрагменты; формулировки местами многословны. Источники: стр. 85–86, 480–544, 31–34. | CPU-инференс 1.5B: 24–28 с на вопрос, не подходит для интерактивного режима без оптимизации. |
| openrouter | minimax/minimax-m3.1-flash:free | 2.13 / 8.73 / 5.36 | RAG-ответы релевантны, следуют контексту, без ошибки «транзакции TCP»; источники совпадают с local. Pure LLM иногда возвращает пустой/обрезанный ответ из-за обязательного reasoning и лимита токенов. | Бесплатный tier OpenRouter: ~20 RPM / ~50 RPD; доступность `:free`-модели может измениться; reasoning обязателен и расходует токены. |

## Выводы

- OpenRouter + MiniMax M3.1 Flash ускоряет RAG в 3–10 раз и подходит для демонстрации.
- Retrieval одинаков для обоих провайдеров: отличается только генерация.
- Для стабильной работы без лимитов использовать local или платный тариф облачного провайдера.
- Для облачной модели увеличен `max_tokens` до 512, так как reasoning-токены расходуют бюджет ответа.
