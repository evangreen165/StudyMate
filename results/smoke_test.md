В вашем примере:

```cpp
int fact(int n) {
    if (n == 0) return 1;
    else return n * fact(n-1);
}
```

### Вопрос 2: Чем отличается TCP от UDP?

Документ: Компьютерные сети (Олифер).

#### RAG

Время ответа: 64.29 с.

**Ответ:**

TCP и UDP — два протокола транспортного уровня, используемых в сетевом взаимодействии. Они отличаются по ряду аспектов:

1. Цель передачи данных:
   - TCP: Цель передачи данных — обеспечить надежность передачи и корректное восстановление потоков байтов.
   - UDP: Цель передачи данных — обеспечить быстроту передачи данных.

2. Тип пакета:
   - TCP: Пакеты, передаваемые по протоколу TCP, называются транзакциями или сессиями.
   - UDP: Пакеты, передаваемые по протоколу UDP, называются пакетами данных.

3. Тип адресации:
   - TCP: Адресация в протоколе TCP осуществляется через порты и сессии.
   - UDP: Адресация в протоколе UDP осуществляется через IP-адреса.

4. Применение:
   - TCP: Обычно используется для передачи больших объемов данных, таких как файлы или приложения.
   - UDP: Обычно используется для передачи малых объемов данных, таких как сообщения, команды или данные о состоянии сети.

5. Применение в сетевом взаимодействии:
   - TCP: TCP является основным протоколом транспортного уровня в сетевом взаимодействии.
   - UDP: UDP также используется в сетевом взаимодействии, но обычно для передачи данных меньшего объема.
