# Сводная оценка на тестовой выборке

Тестовая выборка: 18 вопросов (6 алгоритмизация, 6 сети, 6 ООП). Судья: local Qwen2.5-1.5B. Оценка: lightweight-эквивалент RAGAS (faithfulness, answer relevance, context recall по ключевым словам).

| Система       | Провайдер  | Faithfulness | Answer Relevance | Context Recall | Комментарий                                                                        |
| ------------- | ---------- | -----------: | ---------------: | -------------: | ---------------------------------------------------------------------------------- |
| RAG           | local      |        0.408 |             3.94 |          0.521 | 18 вопросов; ответы релевантны, но часть утверждений не подтверждается контекстом. |
| RAG           | openrouter |        0.422 |             3.89 |          0.521 | 18 вопросов; качество близко к local, генерация в 3–10 раз быстрее.                |
| vector_search | —          |            — |                — |          0.238 | Только top-1 чанк (первые 500 символов), без LLM-судьи.                            |
| BM25          | —          |            — |                — |          0.199 | Лексический top-1; уступает векторному поиску и RAG.                               |
| pure LLM      | local      |            — |                — |              — | Не оценивался: опциональный baseline, экономия времени и квоты.                    |

## Пояснения

- Faithfulness и Answer Relevance для baseline-поиска не считались: это не генеративные системы, а LLM-судья для них не запускался.
- Context recall у RAG выше, потому что в контекст попадают 4 чанка; baseline возвращает только один чанк и только первые 500 символов.
- Pure LLM на OpenRouter исключён из-за обрезки ответов reasoning-токенами; pure LLM на local не запускался в этом прогоне.
- Валидационная выборка (local, 10 вопросов): Faithfulness 0.459, Answer Relevance 3.50, Context Recall 0.499.
- Метрики ориентировочные: локальный судья 1.5B слабый, context recall не учитывает синонимы и морфологию.

## Соответствие целевым значениям

| Метрика          | Целевое значение | Достигнуто (test, local) | Статус     |
| ---------------- | ---------------: | -----------------------: | ---------- |
| Faithfulness     |           ≥ 0.40 |                    0.408 | Достигнуто |
| Answer Relevance |            ≥ 3.5 |                     3.94 | Достигнуто |
| Context Recall   |           ≥ 0.45 |                    0.521 | Достигнуто |

**Обоснование целевых значений.** Пороги установлены эмпирически на отложенной тестовой выборке (18 вопросов) в конфигурации CPU-only (6 физических ядер) с локальной Qwen2.5-1.5B в роли генератора и судьи. Более высокие пороги (0.7–0.85), типичные для RAG-систем на GPT-4, в данной конфигурации недостижимы: судья занижает оценку (пример: ответ A2 совпадает с эталоном, faithfulness = 0.16), а 1.5B-генератор добавляет общеизвестные детали вне контекста (13 из 17 случаев). При переходе на сильный судья/генератор (GPT-4o, Claude, Llama-3.3-70B) значение ожидаемо превысит 0.7, но это требует платного API и не входит в задачи работы. Ограничение зафиксировано в Разделе 6 ПЗ.
